# Tempo 2026 — Modern Men's Fashion Website

Tempo is a modern, responsive men's fashion landing page designed and developed by **Rami Almohamad**.

The project presents a stylish e-commerce brand experience with premium visuals, animated sections, product cards, collection previews, a newsletter area, and a mobile-friendly navigation menu.

## Live Demo

[View Website](https://ramialmoh12.github.io/tempo/)

## Project Overview

This redesign improves the original Tempo website with a stronger visual identity, smoother user experience, and a more professional front-end structure. The design focuses on fashion, confidence, premium menswear, and a clean shopping journey.

## Features

- Modern 2026 fashion landing page design
- Fully responsive layout for desktop, tablet, and mobile
- Sticky glass-style navigation bar
- Mobile burger menu
- Smooth scrolling
- Scroll reveal animations
- Animated statistics counters
- Premium product cards with hover effects
- Collection showcase section
- Free-shipping promotional banner
- About section
- Values section
- Newsletter form interaction
- Scroll-to-top button
- Clean HTML, CSS, and JavaScript structure

## How to Use

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation is required because this is a static website.

## How to Publish on GitHub Pages

1. Open your `tempo` repository on GitHub.
2. Replace the old files with the new files:
   - `index.html`
   - `style.css`
   - `app.js`
   - `README.md`
3. Commit the changes.
4. Go to **Settings > Pages**.
5. Select the main branch and root folder.
6. Save and refresh the live link after GitHub Pages updates.
